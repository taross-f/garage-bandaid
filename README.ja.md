# garage-bandaid

[English](README.md) | 日本語

客席で録ったライブ録音を、あとから聴きやすく整えるためのツールです。

録音から1曲ずつ切り出し、ボーカル・ドラム・ベース・その他（ギターなど）の4つの音（ステム）に分けます。分けた音ごとに音量や音色を整えてから混ぜ直し、配信サービスと同じくらいの音量にそろえます。

ブラウザの画面では設定を変えた複数の案を同時に再生できます。再生位置はそのままで、キー1つで案を切り替えて聴き比べられます。

## 準備

次のものが必要です。

- [uv](https://docs.astral.sh/uv/)
- ffmpeg（録音の切り出しに使います）

```bash
uv sync
```

`.venv` に Python 3.11 と、`uv.lock` に固定したパッケージが入ります。Intel Mac では動きません（torch 2.5.1 に Intel Mac 用のパッケージがないため）。

音を分ける処理は CPU で動かします。4分ほどの曲で、4〜8分かかります。

## 画面で使う（おすすめ）

```bash
uv run studio.py
```

ブラウザで `http://127.0.0.1:8765` が開きます。画面は表示と操作だけで、処理は `studio.py` を動かしている PC の中で行います。音声が外に送られることはありません。

### 1. 曲を追加する

「＋ 曲を追加」を押し、フォルダ内の録音ファイル（wav / flac / aiff）を選びます。曲の範囲を秒で指定すると、前後に3秒ずつ余裕を付けて切り出します。空欄なら全体を使います。

### 2. 設定を変えて案を作る

右側の欄で値を変えて「レンダリング」を押すと、新しい案（版）ができます。各項目の横に、意味と目安の範囲が出ます。

### 3. 聴き比べる

| キー | 動作 |
|---|---|
| `Space` | 再生 / 停止 |
| `0` | before（元の録音の音量だけをそろえたもの） |
| `1`〜`9` | チェックを入れた版 |
| `←` `→` | 5秒戻る / 進む |

波形をドラッグすると、その範囲を繰り返し再生します。

### 4. 決める

気に入った版で「採用」を押すと、その設定が曲の `mix.yaml` に書き込まれ、完成ファイルが作り直されます。

ある曲で決めた設定を、ほかの曲の出発点にもできます。

- 「初期値に」: その版の設定を、これから追加する曲の初期値にします。
- 「初期値を読み込む」: 初期値をいま開いている曲の編集欄に読み込みます。

## コマンドで使う

```bash
# 切り出しと音の分離（曲ごとに1回だけ）
uv run prep.py "recordings/live.wav" --name my_song --start 612 --end 845

# songs/my_song/mix.yaml を書き換えてから混ぜ直す（分離はやり直しません）
uv run mix.py my_song

# 全曲をまとめて混ぜ直す
uv run mix.py --all
```

### カメラなど別の機材の録音を混ぜる

同じ演奏を別の機材でも録っていれば、その左右の広がりと高域を足せます。

```bash
# 動画から音声を書き出す（元の動画は変更しません）
ffmpeg -i source/live.MP4 -vn -c:a pcm_s24le recordings/live_camera.wav

# 曲ごとに、カメラの音を song.wav に時間を合わせて work/camera.wav に書き出す
uv run camera.py my_song recordings/live_camera.wav
```

時間合わせでは、曲の位置を探したうえで、2台の時計の速さの違い（ppm）も測って補正します。合わせたあとは `mix.yaml` の `camera` 節で量を決めます（-60 以下で使わない）。

### 動画の音声を差し替える

```bash
uv run dub.py source/live.MP4 recordings/live_camera.wav exports/live_remix.MP4
```

`camera.py` で時間を合わせた曲だけを、曲の区間で `out/after.wav` に差し替えます。曲の外（MC や歓声）は元の動画の音のまま、曲と音量をそろえます。映像は再エンコードしません。

## できあがるファイル

曲ごとに `songs/<曲名>/` の下に作られます。

| ファイル | 中身 |
|---|---|
| `out/after.wav` | 完成した音（48kHz / 24bit）。元の切り出しと長さ・開始位置が同じなので、映像に合わせやすい |
| `out/before.wav` | 元の録音の音量だけをそろえたもの（比較用） |
| `out/report.json` | before と after の数値 |
| `mix.yaml` | 混ぜ方の設定。各項目に意味と目安をコメントで書いてある |
| `work/song.wav` | 切り出した元の録音 |
| `work/stems/` | 分けた4つの音 |
| `work/diagnosis.json` | 元の録音の診断結果（音割れの割合、音量、音域のバランス） |
| `versions/` | 画面で作った版 |

## 処理の流れ

1. 分けた音ごとに、不要な低音を切り（ハイパスフィルター）、音色を整え（EQ）、音量の波をならします（コンプレッサー）。
2. 元の録音を少しだけ混ぜます。分離で生じるシュワシュワしたノイズが目立たなくなります。
3. 全体の音色と音量の波を整えます。
4. 音量を -14 LUFS（配信サービスでよく使われる基準）にそろえ、瞬間的な最大値が -1 dBTP を超えないように抑えます。

音の分離には [demucs](https://github.com/facebookresearch/demucs)（htdemucs）を使っています。
